# 账号诊断与第三方账号接入

## 第三方账号

移植上游 #107（8d9aaf0b）的独立 URL / API Key 账号，以及 #372（f78b1ca4）的 HTTP 地址支持。新增和编辑账号均可设置地址、密钥与 HTTP / WebSocket 优先传输；编辑不填写新密钥则保留原值。

第三方须兼容 OpenAI Responses 和模型目录接口，不代表支持仅 Chat Completions 的服务。API Key 账号不使用 OAuth 刷新、ChatGPT Cookie 或官方账号身份头；密钥保留在原有加密凭据存储中，不通过账号配置查询返回。账号调度、分组权限、订阅、共享额度、计费和账本继续使用本地实现。没有增加或改写数据库迁移。

## 模型体检 0.6.0

新检测不再选择用户 Key，使用管理员账号诊断通道；消费真实上游额度，不扣用户 Key 额度。旧有 Key 的检测历史和续测保留原有权限、计量路径。

定时探测默认关闭，手动选择最多 50 个账号，默认每 360 分钟一次，可设置 60–10080 分钟。首次执行在保存后的一个间隔后开始。宿主 maintenance v1 每轮最多执行一个账号，与手动检测共享插件串行锁，宿主另有跨插件诊断并发上限 1。关闭页面仍运行；插件停用、宿主停止则不再开始新请求。

计划持久化到插件私有 schedule 命名空间，以 CAS 写入。发送前写 pending；重启或取消后遇到未完成记录先暂停，不重复发送。失败、空回复、截断都会暂停对应账号；只有明确勾选恢复才能解除，普通保存和总开关不会解除。错过周期不补发。

短请求最多等待 20 秒，手动检测最多等待 90 秒；请求携带输出 token 限制。Codex OAuth 后端拒绝 max_output_tokens，该字段按原有适配规则移除，因此 OAuth 的实际资源保护依赖串行、超时、取消和失败暂停，不能宣称上游严格执行 token 上限。

成功请求可能启动平台额度窗口，是否启动以平台规则为准。成功不证明没有风控；401 / 403 / 429 分别保留鉴权、权限或区域、限流或额度不足的可能性，不把普通错误推断为封禁。

## 宿主扩展契约

RPC v5 上新增本 fork 的 `host.account.probe` 回调，非上游标准 SDK 能力；插件 0.6.0 须与此次宿主改动配套安装。

- 参数：`account_id`、`model`；二进制部分为 OpenAI Responses JSON，最大 64 KiB。
- 仅宿主绑定的根管理员 management 调用或已发布插件 maintenance 根调用可用。子调用、System、AdminApiKey 和 management 阶段的 Plugin actor 均不能冒充权限。
- 禁止 tools、previous_response_id 和参数与正文模型不一致；使用既有原生 AccountProbe，固定账号，不借用用户 Key。
- 返回 text、complete 和 status；错误只返回 HTTP 状态、发送事实及白名单错误码，不泄漏原始上游错误正文。
- 共用宿主诊断并发限制；取消、超时按结果可能未知处理。

本次本地验收不部署生产、不调用真实付费模型。具体测试结果在任务回复和本地 `.runtime` 日志中记录。

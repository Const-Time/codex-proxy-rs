# 用户与分组额度改造

目标：管理员创建用户（默认普通用户）并授权分组；任何角色仅管理自己的密钥；普通用户仅查看自己的使用记录；日/周 USD 配额由管理员在分组配置，按用户和分组共享。新密钥必须且只能绑定一个授权分组。

密钥保留仅本人可再次读取的体验。部署级管理 API Key 不具备个人密钥访问权限。用户禁用后会话和客户端访问失效。用户改密后旧会话失效。

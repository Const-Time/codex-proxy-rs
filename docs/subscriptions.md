# 用户订阅与配额

在“用户管理 → 编辑用户”中，为每个授权分组分别设置额度倍率。例如分组周限为 100 美元，某用户设为 2 倍，其周限就是 200 美元；同一分组内其他用户不变。该设置同时作用于日限和周限，与分组的模型计费倍率独立。

“订阅管理”位于“分组管理”下方，可按用户名和分组筛选，查看有效限额、当前用量、下次刷新和最近重置原因。只有管理员可以访问。新订阅在第一次请求准入时建立窗口；已到期但尚无新请求的窗口等待下次准入开始。

订阅列表每个用户分组一行，用户和分组独立列展示。勾选订阅后点击“重置选中订阅”并在弹窗确认，仅影响选中的用户分组对。支持当前页全选及跨页选择，切换筛选会清空选择，每次最多 500 项。它清除当前日/周已用配额并重新开始周期，不删除请求记录、消费账本或密钥。普通用户的“使用记录”与管理员“使用统计”仍保留历史消费。

账号在本系统内主动重置成功，以及检测到上游自行重置、自然额度恢复时，均会联动所有关联分组下的用户配额。多个账号关联同一分组时，任一账号检测到重置即可触发。后台每分钟核对已取得的上游配额，不要求一直打开管理页面。

外部重置仅依据账号级 7 天周窗口的刷新边界向后推进超过 60 秒。短周期窗口变化或用量比例下降不触发；周窗口时间没变时不重置。首次观察、重复快照及过期快照不触发。若上游没有提供有效窗口变化、没有刷新快照，或重置后已在两次观察之间消耗大量额度，则不能保证识别；可使用订阅管理手动重置。

本次升级执行迁移 0012，保留既有授权倍率与消费记录。管理员可编辑自己的分组授权，首次保存后按明确勾选的分组控制个人密钥，不影响管理权限。升级前备份数据库；不要修改旧迁移或手动清空账本。退回旧版本时应恢复对应的数据库备份。

旧版本已经发生的错误重置不会被本次升级反向改写，以免覆盖后续有效消费；历史请求及消费账本仍保留。
# 自动重置开关

系统设置 → 运行参数 → “自动重置订阅分组配额”，默认开启，保存后生效。关闭后账号主动重置和上游周窗口变化均不触发订阅联动重置；手动重置选中订阅以及订阅自身的日、周到期刷新不受影响。重新开启会清除旧观察基准，首次观察仅记录新基准，不补做关闭期间的变化；关闭期间已处理的主动重置事件仍保留去重记录。API 字段为 `subscriptionAutoResetEnabled`，更新设置时省略该字段则保留现值。

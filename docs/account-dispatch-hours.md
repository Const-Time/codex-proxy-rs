# 账号每日调度时段

在「账号管理 → 编辑账号 → 限制每日调度时段」启用，选择时区并添加 1–16 个时段。默认关闭，不限制时间。

每天按所选 IANA 时区重复，开始时间包含、结束时间不包含。22:00–02:00 表示跨午夜；多个时段取并集。开始和结束不能相同。夏令时按当地时钟判断，重复小时均适用，跳过的小时不会补执行。

范围外不再分配新请求，已开始的请求正常完成。固定账号、会话亲和及诊断探测同样受限；账号的启用状态、额度和凭据有效性仍分别检查。关闭时段限制不会启用一个已经禁用的账号。

管理 API 的单账号更新和批量更新支持 `dispatchHours`，省略保留原设置：

```json
{"enabled":true,"timeZone":"Asia/Shanghai","windows":[{"start":"09:00","end":"18:00"},{"start":"22:00","end":"02:00"}]}
```

数据库迁移 0054 为现有账号设置默认关闭。导入和刷新凭据保留已有时段配置。

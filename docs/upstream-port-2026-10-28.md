# 2026-10-28 插件 RPC v7 适配

本轮基于上游 `dd529d07ec8e13b3d2b504f45e51b494d3215e2a`，发布宿主 3.15.0、模型体检 0.9.0 和共享额度管理 0.4.0。

## 合并范围

- #513、#525、#529：阶段独立调用预算、RPC v7 挂起/恢复和回调消费确认、统一调用表及只读运行负载；结合本地实例权限、进程监督及取消链适配。
- 维护任务按实例 revision 和实际进程区分。无关实例发布不会取消正在执行的维护；停用、升级、Core 不可用及宿主退出仍撤销原调用，替换前等待取消确认。
- #531：WebSocket 错误转换为 SSE 后保留 Retry-After；兼容本地既有数组头值解析。
- #532：受管适配器只对宿主观察到的单次 HTTP 429 建立重放证明。第二次请求、辅助请求、通用 HTTP/模型/服务调用、WebSocket、任何已输出事实或正文均不具备此证明。
- 模型体检移除账号诊断对正常调度 enabled 的过滤。手动与定时检测仍绑定真实账号，保持管理员权限、凭据身份校验、串行租约、取消及原诊断限额；不会改变账号 enabled。

## 兼容边界

旧 RPC v5 制品不能在新宿主运行。先升级宿主，再在原实例切换配套插件制品，保留配置、私有状态、检测历史、定时开关和暂停状态。本次没有数据库迁移，也不变更插件状态 schema。

SDK 的类型集合不是宿主能力声明。当前运行时仍支持 adapter v4、middleware v4/v5、model_catalog v1；#509 的 adapter v5 账号范围、#511 的 middleware v6 出站组合、#533 的 model_catalog v2 以及新身份/访问/额度回调尚未接入。请求与响应的原有载荷限制保持不变。完整矩阵见 [插件安装与管理](plugins.md)。

本地用户、订阅、共享额度、倍率和账本继续由原 Core/Store 执行。管理员免 Key 诊断仍是本 fork 的版本化扩展，不代表任意上游 RPC v7 宿主均可运行本插件。

## 验证范围

离线测试使用原始上游 SDK、实际子进程、隔离 PostgreSQL/Redis 和受控上游回包，覆盖正常权限与结算、插件服务、维护取消、状态恢复及安全重放条件。配套模型体检安装包在无网络、非 root、只读根文件系统和 noexec 临时目录下验证 Meow 36/36、ModelTrace 3/3、暂停恢复和历史读取。测试不调用生产账号。

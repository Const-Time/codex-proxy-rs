## 适配边界

- 保留 User、Key、分组范围与倍率快照、共享账本和取消安全结算。未引入上游 API Key 账号体系或插件中间件生命周期。
- 0001–0026 迁移未修改，本轮不新增迁移。
- 仍保留 OpenAI WS origin 级连接保护；删除的是影响整个 Provider 的 Redis 全局 circuit。
- 账号停用仅改变调度资格，不能阻止 OAuth 轮换，也不能由刷新动作重新启用账号。
- 目录来源限制展示，不把“某账号未发现模型”变成新的推理权限白名单。
- #297 的“亲和账号优先排队”未导入：本地没有上游等待队列，需另行设计等待期限、取消与公平性。此次只修错误分类。
- #295 调度偏好、完整插件体系、guardian 与 voice 新功能未导入。
- 原工作目录的部署文件及发布脚本修改未动；实现位于独立 `codex/upstream-fixes-plugins` 分支。

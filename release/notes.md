# v3.9.0

## 代理配置表单

- 新增结构化连接配置：选择 HTTP、HTTPS、SOCKS5 或 SOCKS5H，分别填写 IP / 主机名和端口，无需手写代理 URL。
- 支持无需认证或账号认证，密码可留空；支持 IPv4、IPv6 和域名，并校验端口范围及地址格式。
- 自动编码账号密码中的特殊字符，密码默认隐藏，可按需显示。
- 编辑已有代理时默认保留原连接及认证信息；只有主动选择“修改连接信息”才替换连接，原密码不回显。
- 保留请求地区设置、“保存代理”和“保存并测试”，适配手机布局。

## 额度估算与恢复

- 修复已附加本地用量的额度窗口被错误跳过，导致 5 小时及周额度估算一直不生成的问题。
- 缺失可选套餐信息不再被误判为套餐变更，避免错误排除有效估算样本。
- 优化耗尽后的恢复确认：同一重置时间的连续有效观测可恢复账号，不再要求每次确认都推进重置时间。
- 重置时间过期并经过宽限期后，以一分钟间隔重试确认，避免继续等待半小时；保留连续观测保护，防止错误恢复。

## 上游修复移植

- #111：在线更新与回滚默认复用实际静态资源目录，保留显式配置及本分支的发布仓库设置。
- #112：套餐信息随额度观测原子更新，凭据刷新保留现有账号资料，避免旧资料覆盖新状态。
- #110：代理出口检测使用双栈地址查询，支持 IPv4 / IPv6。
- #122：管理员对指定账号的诊断允许检查已禁用账号，不改变正常请求的调度规则。

## 升级说明

- 无新增数据库迁移，已有代理无需重新录入。
- Docker：`ghcr.io/const-time/codex-proxy-rs:3.9.0`，支持 Linux amd64、arm64；发布流程同时更新 `latest`。
- 提供 Linux amd64、Linux arm64 和 macOS arm64 二进制归档。

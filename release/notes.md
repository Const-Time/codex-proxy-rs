# v3.14.0

## 插件与账号诊断

- 升级 RPC v5 / upstream adapter v4，支持原始 HTTP 字节头、trailers、WebSocket 消息和完整响应观测，保留失败 attempt 的用量事实。
- 模型体检插件配套升级到 0.6.0：新检测不再选择用户 Key，使用管理员账号诊断通道；旧有 Key 检测历史和续测保持原计量方式。
- 新增默认关闭的定时账号探测，只检查手动选中的账号；间隔可配置，串行执行，失败和结果未知时暂停，不自动重发或补发错过周期。关闭浏览器后仍可按计划执行。
- 诊断消耗真实上游额度，不扣用户 Key 额度；是否启动额度窗口由上游规则决定，成功不等于账号一定没有风控。
- 共享额度管理插件升级为 0.3.0，继续使用原权限、订阅和账本。

## 第三方账号与 Credits

- 新增兼容 OpenAI Responses API 的第三方 URL + API Key 账号，支持新增、编辑、保留原密钥及 HTTP / WebSocket 优先传输。
- 第三方账号使用自身地址和认证，不携带 OAuth Cookie 或官方账号身份头；保留本地调度、分组权限、计费及历史用量。
- 账号额度面板新增 credits 展示，区分零、无限和未知余额，保留十进制精度并清除过时观测。

## 稳定性与资源使用

- 改进 WebSocket 取消、发送泵回收、连接池与握手错误恢复，避免阻塞关闭和异常遗留。
- 修复重试与出站连接预算、WebSocket 错误响应和流式错误后的资源释放。
- 批量读取账号额度缓存，减少账号列表重复查询；后台任务成功后清除健康告警并重置退避。
- 更新相关安全依赖，保留现有本地用户、订阅、共享额度、倍率及账本逻辑。

## 升级说明

- **RPC v5 是新兼容边界。升级宿主后，请将模型体检切换至 0.6.0、共享额度管理切换至 0.3.0；旧 RPC v4 制品不能继续运行。请在原实例切换制品，保留配置与私有状态。**
- 两个配套插件最低要求宿主 3.14.0。免 Key 诊断为本 fork 的宿主扩展，不代表任意上游 RPC v5 宿主都兼容。
- 本次不新增或改写数据库迁移，不清理历史、不重算扣费；此前停用的主动状态维护保持停用，新增插件定时探测须手动启用。
- 本地完成后端回归、前端检查及离线插件安装包验收；未用生产账号发起真实模型请求。

# v3.13.0

## 插件通信与资源使用

- 直接升级进程通信到上游 RPC v4：业务 JSON 与请求快照移出控制元数据，队列复用一次编码结果，并按实际读取进度分配载荷缓冲。
- 缓存已编译的配置 / 状态 schema，限制同时准备的插件数量；单次无效业务响应不再中断同进程的其他调用，返回结果前释放本次调用资源。
- 管理能力支持 v2、中间件支持 v5 的入口快照，同时保留本地已实现能力合同；不代表所有上游新能力均已实现。
- 配套共享额度插件升级为 0.2.0，模型体检插件升级为 0.4.0。旧 RPC v2 制品需要替换，无法直接继续运行；请在原实例切换新制品，保留配置、状态与检测历史。旧制品不会阻止主服务启动，可继续停用或删除。

## 稳定性与使用统计

- 每个出站代理可设置 WebSocket 连接上限，0 表示不限；计算连接中、活跃和空闲连接，不驱逐仍被下游持有的连接。
- 修复可用 credits 与额度窗口重置后的账号恢复；临近重置采用有界的快速回查。
- 保留账号切换失败前的真实上游错误；独立搜索遵守账号模型允许 / 禁止列表，无法确认模型时只选无限制账号。
- 支持 multipart 图片编辑请求，保留重复图片与合法扩展参数，继续使用现有入口内存预算。
- 管理及个人使用统计新增最近 31 天内的自定义日期范围，保留今日 / 7 天 / 30 天快捷选项；昨日对比独立读取，避免仅查今日时误显示为零。
- 翻页失败恢复已确认页码和每页数量，筛选变化清空旧结果，迟到响应不会覆盖新查询。
- 发布完成后才更新 latest，串行校验已发布稳定版本，阻止较旧流水线覆盖新版本。

## 数据与升级

- 仅新增 0046 代理 WebSocket 限额迁移；既有迁移不修改。固定迁移文件换行，并让迁移变化触发重新编译，避免不同构建缓存嵌入不同迁移内容。
- 保留本地用户权限、订阅、共享额度、倍率和消费账本，不清理历史、不重算扣费。
- RPC v4 是本次插件兼容边界。升级宿主时应同时准备配套插件包；第三方插件需要按支持矩阵确认能力版本。

# v3.12.6

## 订阅重置修复

- 修复未设置日限的订阅仍显示“每日周期重置”的问题：内部日统计继续正常换窗，但不再产生每日额度重置事件，也不覆盖最近重置时间；周用量保持不变。
- 升级时修正当前无日限订阅的错误最近重置显示：优先恢复有明确用户、分组归属的非每日重置记录，无法确认则显示未知。保留旧审计、消费账本、用量及周期边界。

## 账号与分组页面性能

- 账号、用户页面的分组选择器改用轻量目录，不再加载完整分组统计和成员信息。
- 账号额度估算最多并行处理四个账号，仍受全局查询预算约束；单账号估算失败不影响其他账号显示。
- 分组历史费用复用小时汇总；近期、非整小时边界、未回填和待修正的数据仍读取原始记录，正确处理迟到费用补全和历史归属。
- 分组页面只在禁用、删除确认时加载 Key 引用，减少页面首次打开的请求。

## 升级说明

- 新增 0044、0045 数据库迁移，升级前建议备份。不会清理请求、诊断内容或消费账本，不重算扣费。
- 既有历史汇总由后台分批重建，完成前回读原始数据；性能收益随回填逐步生效，费用不会暂时显示为零。
- 保持单副本部署，不要混跑旧版统计 worker。插件无需重新安装。
- 本地 10 万条模拟请求测试，分组查询从约 132ms 降至 4ms，结果一致；线上表现取决于数据规模和运行环境。

# v3.9.1

## 账号模型白名单 / 黑名单

- 移植上游 `zyycn/codex-proxy-rs` PR #105，支持账号级“不限制 / 白名单 / 黑名单”。
- 账号管理的单账号、批量编辑及导入设置均可配置模型限制；支持勾选目录模型或输入精确模型 ID 后回车添加。
- 匹配全局模型映射后的上游模型 ID，区分大小写，不支持通配符；最多配置 256 个 ID，每个最多 256 字节。
- OpenAI / xAI 实际调度、重试换号和会话亲和遵守冻结的模型政策；合规账号满载或不可用时，不会绕到被禁止的账号。
- 客户端模型目录按授权账号池的政策过滤，导入导出保留模型限制。
- 批量仅修改模型限制时，不覆盖账号原有启停状态、并发、权重、分组和代理。省略模型政策时保留原值，选择“不限制”显式清除限制。
- Images、独立 Search 和管理员连接测试沿用原有行为，不受本次文本模型限制影响。

## 兼容与升级

- 新增数据库迁移 `0020_account_model_access.sql`，启动时自动执行；升级前请备份数据库。
- 旧账号默认“不限制”，保留所有原有账号事实；`0001` 至 `0019` 历史迁移及校验值不变。
- 保留本分支的额度估算、额度恢复和结构化代理配置，不引入上游账号备注、并发队列或原生模型目录重构。
- 本次未替换线上实例；发布包与镜像供管理员自行升级。

## 验证

- 后端 2,130 项测试通过，包含真实 PostgreSQL / Redis 集成测试、`0019 → 0020` 升级、模型分流、重试与亲和限制、导入导出和批量设置保留。
- 前端 24 项测试、lint、类型检查、生产构建及后端严格 Clippy 通过。
- 本地页面验证白名单保存回显、批量黑名单和非法 ID 拒绝；实际管理接口验证三种模式往返及无关设置保留。

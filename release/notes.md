# v3.9.4

## 使用统计：Turn-state 明细

- 管理员「使用统计 → 请求明细」在时间列后新增 TURN-STATE，依次展示字符数徽章、截断的状态值及复制按钮；悬停可查看完整内容，复制保留完整值。
- 使用记录详情弹窗同步展示上游返回的 turn-state；缺失值统一显示 `—`。
- 记录 HTTP 响应头及 WebSocket 响应 metadata 中实际上游返回的 `x-codex-turn-state`，不把请求中注入的值当作上游返回值。
- 通过现有使用记录观测字段持久化，列表仅提取所需字段；普通用户的个人使用记录不暴露上游状态令牌。
- 字符数只表示长度，不根据长度标注模型能力、正常或降智。

## 兼容与升级

- 无新增数据库迁移。更新后产生的新请求开始记录；历史记录缺失的 turn-state 无法补回。
- 不改变指纹收敛、turn-state 注入、续接或候选维护策略；不新增 turn-state 管理或自动接管功能。
- 保留 v3.9.3 的账号文件重新授权功能。
- 本次仅发布软件包与镜像，不自动更新线上实例；升级前建议备份数据库与配置。

## 验证

- 前端 29 项单元测试、格式检查、类型检查与生产构建通过。
- 后端 2,156 项测试通过，包含 PostgreSQL / Redis 集成测试；格式检查及严格 Clippy 通过。
- HTTP / WebSocket 上游状态采集、数据库读写、管理员展示与个人记录隔离回归测试。
- 使用实际表格组件验证字符数、截断、缺失值及复制完整 312 字符值。

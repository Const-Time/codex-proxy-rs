# v3.9.3

## 账号文件重新授权

- OpenAI / xAI 的账号重新授权弹窗增加「账号文件」方式，支持上传 JSON 文件或直接粘贴内容；保留 OAuth 授权方式。
- 打开重新授权弹窗不再自动生成 OAuth 链接，可先选择授权方式。
- 文件重新授权绑定原账号，只轮换凭据，不新增账号，不覆盖账号名称、代理、分组、调度权重或模型访问规则。
- 校验凭据身份与目标账号是否一致，拒绝身份不匹配、多账号文件及批量账号包；提交时校验凭据版本，避免并发变更被旧凭据覆盖。
- OpenAI 支持原生 tokens 文件及现有单账号 OAuth 导入格式；xAI 继续使用 OAuth 凭据验证流程。文件内的身份标签不能代替凭据身份校验。

## 兼容与升级

- 无新增数据库迁移，原有账号导入接口保持兼容；重新授权通过可选 accountId 定位原账号。
- 保留 v3.9.2 的额度续写恢复、模型观测与计价、停用账号目录及默认 store=false 修复。
- 本次仅发布软件包与镜像，不自动更新线上实例；升级前建议备份数据库与配置。

## 验证

- 后端 2,154 项测试通过，包含 PostgreSQL / Redis 集成测试及账号文件身份校验、定向凭据轮换回归；最终凭据提交保护补充验证通过。
- 前端 27 项测试、lint、类型检查、生产构建、后端严格 Clippy 和格式检查通过。
- 使用实际重新授权弹窗检查 OAuth / 账号文件切换、JSON 输入与提交按钮状态；未使用真实上游账号执行生产重新授权。

# v3.10.4

## 修复轮换出口检测缓存

- 修复自动维护按代理入口复用 60 秒出口检测缓存、导致连续采集显示相同 IP 和检测时间，而手动测试不断变化的问题。
- 轮换入口、旧版 gateway 和 API 提取式代理的每次采集均重新检测出口，不读取或写入入口级快照缓存；手动检测也不会给轮换采集填充缓存。
- 固定采集及业务出口快照仍保留最多 60 秒缓存，手动测试继续强制重新检测。
- 更新探测记录、出口快照提示和代理池说明，明确区分独立检测连接与实际模型请求；历史记录保留原快照，不回填或伪造旧 IP。

## 轮换行为与边界

- 保留候选未入选或采集网络失败后重新建立代理连接的逻辑，API 模式下一次采集重新提取代理；固定出口每周期只采集一次。
- 新增回归验证：轮换/旧版 gateway 连续三次未入选时建立三条独立连接，并分别检测出口；小时预算耗尽后不再发送探测。
- 新增固定与轮换模式切换时缓存不串用的测试，以及 401/403/407/429 响应停止本轮采集的测试。
- 新连接或重新提取不保证供应商分配不同 IP。独立检测 IP 不是上游请求实际出口的证明，不能据此认定某个 IP 已经执行过模型探测。
- 保留每周期采集次数、账号小时预算、请求间隔、认证失败暂停和上游限流冷却，不切换出口绕过拒绝。

## 升级须知

- 相比 v3.10.3 无新增数据库迁移，不修改已发布的 0001–0024 迁移。
- 从 v3.10.2 或更早版本升级仍会执行 v3.10.3 引入的 0024 独立探测记录迁移，请提前备份数据库与配置。
- 修复在升级后的新探测记录中生效，历史记录不会重新检测或改写。
- 本次仅发布软件包与镜像，不自动升级或重启线上实例。

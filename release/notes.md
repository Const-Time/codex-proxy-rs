# v3.18.2

- 用量统计改为按卡片和所选性能指标加载；未选择的耗时分位数和并发不再同时计算。卡片独立加载、取消旧请求，并短暂复用相同筛选条件的结果。
- Redis 账号运行状态改为分批读取，减少选号时的网络往返；配置刷新遇到并发修改时有界重读，避免发布已知过期快照。
- 新增上游 Retry-After 等待上限设置，默认 240 秒。超过上限时按原安全条件换号或返回错误，不缩短等待后重复请求。收紧模型不支持错误的识别，避免误判普通参数错误。
- 上游 WebSocket 增加保活；首次未启用搜索的连接在后续请求新增搜索工具时重建并发送完整请求。支持更大的 Codex 原生模型目录，并限制目录缓存的正文总量。
- 适配 Codex Guardian 父响应路由亲和，按 Client Key 和账号隔离，保留 Cookie 来源、路径和有效期约束。
- 批量编辑账号新增调度“保持不变”选项，避免只修改分组、代理等配置时意外启停账号。
- 容器 CI 使用压缩 Cargo 缓存，按平台和依赖复用，减少重复导出及临时磁盘占用。
- 新增数据库迁移 0048 保存重试等待上限；旧迁移保持冻结。新增 local.settings.v3，原 v1/v2 插件更新设置时保留新配置；现有插件无需重新上传。
- 已通过 3,505 项全工作区后端测试、84 项前端测试、严格 Clippy、前端构建、浏览器交互、迁移校验和 BuildKit 缓存往返测试；12 项已有后端测试按原配置跳过。
- 修正 WebSocket 连接池测试目录布局，满足全工作区架构检查。Trivy 改为直接下载 GitHub 官方固定版本制品并校验固定 SHA-256，避免下载中转域名解析失败；保留原有镜像漏洞扫描和发布门禁。

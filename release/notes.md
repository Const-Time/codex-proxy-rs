# v3.11.0

## 模型定价与自动同步

- 新增「系统设置 → 模型定价」，支持新模型单价、标准/Fast/Flex/长上下文档位、模型倍率和批量编辑，无需重新发版即可配置新模型价格。
- 接入 Sub2API 的 LiteLLM 格式社区价目，后台启动后首轮检查、之后每 10 分钟检查一次；严格验证 SHA-256，只有摘要变化时才重新下载 JSON。
- 默认只自动加入未知模型；管理员可选择自动更新已有价格或仅手动同步。人工单价与倍率始终优先，同步失败或来源删项不会清空已验证价格。
- 内置 GPT-6 Sol / Luna 分档价格。价格按请求冻结并持久化费用明细，改价不重算历史账单、不改变进行中的请求；保留分组倍率、用户额度和共享订阅账本。
- 社区价目不是厂商实际扣费接口。缺失缓存价格、未知上下文规则或无法表达的费用不会猜测或按零计价；历史未知费用不会自动补扣。

## 上游修复与兼容改进

- 修复运行快照发布、账号选择竞态、取消时结算与租约清理，以及流创建前失败记录；保留现有账号并发限制。
- 改进 system/string/reasoning 请求兼容、流内 invalid_prompt 分类、同账号 metadata 身份隔离和额度耗尽错误语义。
- 改进原生模型目录、客户端版本适配与有界缓存，保留模型权限和旧版 Fast 能力兼容。
- 正常账号过期额度窗口自动刷新；重新启用账号不抹除额度或错误事实；容量预测使用本周期累计与剩余样本。
- 增加 Key × 模型用量统计、管理员历史账号名称/邮箱搜索；个人用量和上游账号身份仍保持权限隔离。
- 新增表格列显示/排序持久化、遗留启动配置字段告警，并更新 TLS 依赖。

## 在线更新与发布附件

- 在线更新转为后台执行，HTTP 断开不会取消更新；支持发行通道与发布说明，保留准备失败的具体终态提示。
- 发布匹配版本的 compose 与配置模板附件，并纳入校验和；二进制归档同时携带部署配置模板。

## 升级须知

- 新增 `0025_model_pricing.sql`、`0026_pricing_sync.sql`，启动时由现有迁移机制应用；升级前备份数据库。
- 已发布的 0001–0024 迁移保持不变，无需修改现有启动配置。
- 运行实例需能通过 HTTPS 访问固定的 GitHub Raw 价目来源；无法访问时继续使用人工、已同步或内置价格。

- 本次只发布软件包与镜像，不自动升级或重启线上实例。

# v3.8.4

## 额度预测

- 移植上游的新额度预测方式，以同一额度周期内的用量和百分比配对采样，按至少 5 个百分点的连续区间计算，结合最近区间减少单点波动。
- 原始费用与倍率后计费分别估算，并增加预计总 Token、剩余 Token 和剩余额度。费用缺失时不再沿用旧的低估值，也不会把缺失金额显示成零；可用的 Token 预测仍独立展示。
- 额度重置、套餐变化和用量回落会重新建立采样。中途导入的账号需要积累有效区间，样本较少时显示初步估算提示。
- 预热请求不计入推理用量，仍保留有效的额度观测。

## 代理地区与时区

- 代理新增请求地区设置，支持自动检测、手动指定及透传；账号通过绑定的代理继承地区和时区。
- 自动模式在测试代理时通过该代理查询出口 IP 和地区并缓存，正常请求不会额外发起地区查询。更换代理地址会清除旧的自动检测结果。
- OpenAI 请求根据所选账号的代理设置调整结构化环境信息及搜索位置；普通消息文本保持不变。使用动态出口代理时，可重新测试以更新检测结果。

## 上游传输适配

- 移植上游 #86，调整 OpenAI HTTP 的 TLS 依赖和传输配置，保留自定义 CA、SOCKS、IPv6 以及 WebSocket 现有支持。

## 表格样式统一

- 用户管理、订阅管理和操作日志统一使用系统表格组件，对齐表头、行背景、间距、状态与操作按钮样式。
- 保留手机端一条记录一张卡片的排版，订阅额度占满卡片宽度；修正分页布局，并处理长邮箱、请求路径和 IPv6 地址的换行。
- 保留订阅选择、筛选及原有操作权限，无日限的订阅继续隐藏日限。

## 验证与升级

- 后端全量测试、严格 Clippy、前端 7 项测试、lint、类型检查和生产构建通过；已核验桌面及手机端表格交互。
- 新增数据库迁移 0018，用于保存代理地区设置；已发布迁移保持不变并通过冻结校验。
- Docker：`ghcr.io/const-time/codex-proxy-rs:3.8.4`，支持 Linux amd64、arm64；正式发布后同步更新 `latest`。

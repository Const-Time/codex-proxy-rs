# v3.7.1

## 用户管理

- 用户列表新增禁用、启用和删除操作，执行前显示确认提示。管理员账号禁止删除或禁用。
- 编辑用户时可单独设置新密码，或自动生成 32 位随机密码；生成的密码仅在成功后显示，可一键复制。
- 管理员可修改普通用户及自己的密码。改密后原有登录会话失效，密钥、授权分组与历史记录保留；重置自己的密码后先保存新密码，再重新登录。
- 禁用用户后禁止登录及使用已有密钥发起新请求，重新启用后可继续使用原密钥。
- 删除用户时撤销其密钥和分组授权，保留历史请求及审计记录；删除后的邮箱可用于创建新用户。
- 启停、删除和密码操作写入操作日志，日志不记录密码；随机密码响应禁止缓存。

## 错误提示与部署排障

- 账号加载失败时显示具体错误和重试入口，首次加载失败时统计卡显示占位符，避免将读取失败误认为账号数量为零；刷新失败时保留上次加载的数据。
- 使用统计明确指出加载失败的筛选项及错误原因。
- 部署文档补充 Redis 数据目录权限导致 RDB 保存失败、请求 503 和账号列表读取失败的排查与修复步骤。升级应用不会自动修改服务器 Redis 目录权限。

## 升级与验证

- 新增迁移 0016，保存用户删除状态并允许复用已删除用户的邮箱；已发布迁移 0001–0015 保持原样。升级前备份数据库。
- 625 项管理、API 和存储测试通过；严格 Clippy、迁移冻结校验、前端 lint、类型检查和生产构建通过。
- 本地接口验证权限隔离、管理员保护、启停恢复、随机及手动改密、旧会话失效、删除密钥、邮箱复用与日志脱敏，并检查用户列表和编辑窗口布局。
- Docker：`ghcr.io/const-time/codex-proxy-rs:3.7.1`，支持 Linux amd64、arm64；正式发布后同步更新 `latest`。

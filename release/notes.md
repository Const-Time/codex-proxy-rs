# v3.12.1

## 插件安装与运行

- 管理员可上传可信插件包、配置实例、启停、切换版本及打开管理页面；实例与私有数据随数据库备份恢复。
- 支持管理、外部认证、模型目录、路由、调度、重试、中间件、上游适配器、维护、观察和命令行能力。插件模型调用沿用本人 Key 的权限、共享额度、倍率与结算。
- 插件执行容量与等待下游的调用分离，避免长请求耗尽执行槽位；总在途、排队和回调仍有独立上限，过载返回可识别错误。
- 提供可独立安装的共享额度管理插件，支持额度查询、分组基础限额修改和指定用户订阅幂等重置。

## 请求稳定性

- Responses SSE 准入后等待首事件时发送保活；生命周期前导事件及时交付，已发送的业务输出和结果不确定的请求仍禁止自动重放。
- 单轮速率限制不再误伤账号健康或触发代理重试；额度观察时间更新不再导致无意义的账号重选。
- 修复 Cookie 在失败处理和复用 WebSocket 时被重复应用的问题。
- 更新 rustls 和 quinn-proto 依赖。

## 请求记录与账号导入

- 请求列表和详情新增单条生成速率 tokens/s，按输出 Token 数除以首 Token 到完成的耗时计算；缺少有效数据时显示“—”。
- 优化用量与错误记录的深分页，保持精确总数、稳定排序和用户过滤；同次计数和明细共用数据库快照。
- 历史查询取消后，连接预算持续持有到数据库回滚结束；相同计费事实聚合传输，保留逐条舍入和原账本语义。
- OpenAI 批量导入按条处理，部分失败后可保留输入并跳过已确认成功的条目；拒绝没有刷新令牌的已过期访问令牌。

## 升级说明

- 包含此前 v3.12.0 标签下的插件改造及后续修复；v3.12.0 发布构建取消后未生成正式 Release。
- 从 v3.11.4 升级会补齐插件相关数据库迁移，升级前请备份 PostgreSQL；数据库降级需要恢复升级前备份。
- 插件按可信本地进程运行，需使用与宿主平台匹配的制品。第三方插件须按其实际能力和平台单独验证。
- #423 按本地架构适配分页、费用聚合与查询预算，本版未引入另一套后台汇总表。
- 本版不内置账号模型体检第三方插件；发布不会自动升级线上实例。

## 发布产物

- Docker：`ghcr.io/const-time/codex-proxy-rs:3.12.1`，Linux amd64/arm64，稳定标签 `latest` 同步更新。
- Linux amd64、Linux arm64、macOS arm64 网关归档内附 `cpr-plugin` CLI，另提供对应平台共享额度管理插件包。
- 部署模板、校验和与构建证明。

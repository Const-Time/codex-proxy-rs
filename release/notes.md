# v3.8.5

## 独立额度预测弹窗

- 账号管理展开详情后，点击“模型使用排行”标题右侧的趋势图标即可打开额度预测。
- 按账号实际额度窗口切换，展示已用比例、预计总 Token、剩余 Token、原始费用与倍率后计费，并标明采样区间、样本不足和费用缺失。
- 保留原来的内嵌预测区域，弹窗与展开区使用同一份预测数据；打开弹窗不查询上游，点击“刷新额度”才更新。
- 沿用现有主题，适配桌面、手机和深色模式。

## 请求参数诊断

- 管理员在“请求详情 → 请求诊断 → 上游请求参数”中，可查看新 OpenAI 请求在各次尝试中准备的参数快照；同时纳入导出的诊断包。
- 记录绑定代理 ID、自动/手动/透传模式、最近检测出口 IP 与时间、代理提供的地区时区，以及结构化环境和搜索位置的实际改写数量。
- 记录上游 User-Agent、客户端版本与来源、传输及请求压缩参数；会话和路由标识仅保存 SHA-256 摘要，认证及 Cookie 只保存是否携带。
- 区分发送前参数、报文发送及响应观测，显示 WebSocket 连接复用情况。检测 IP 不代表每次请求的真实出口，准备的参数不等于上游已接受，也不代表实际 TLS 指纹或风控判断结果。
- 无需开启完整报文日志。旧记录及其他尚未采集的平台显示未保存快照，不使用当前配置补写历史；摘要继续遵守诊断大小限制。

# v3.4.2

## 修复

- 修复删除迁移分组或已有额度记录的分组时，外键引用冲突被误报为“依赖服务暂不可用”的问题。
- 删除前同时检查密钥、用户分组额度窗口和计费账本引用；有引用时返回明确的冲突提示。已有额度或计费记录的分组可改为禁用。
- 未被上述记录引用的分组可正常删除，清理分组授权和成员关系时保留账号本身。历史额度、账本及删除失败时的配置版本保持不变。
- 增加真实 PostgreSQL 回归测试，覆盖额度窗口、已删除密钥的计费记录、正常删除及事务回滚。

## 升级

本补丁不包含新的数据库迁移，可从 v3.4.1 直接升级。有额度或计费记录的分组即使当前账号数和显示费用为零，仍需保留；如不再使用，请禁用。

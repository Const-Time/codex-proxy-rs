# v3.8.0

## 手机端页面排版

- 手机端表格改为一条记录一张卡片，字段名称与内容左右排列，操作集中在卡片底部；桌面端继续使用原有表格。
- 调整所有菜单页面的窄屏布局，包括概览、用户、分组、订阅、账号、代理、统计、日志、设置、密钥、使用记录、个人资料和主题设置。
- 筛选条件支持展开与收起，统计指标、图表、额度和弹窗适配手机宽度；保留列表排序、全选、批量操作及展开详情。
- 页面标题旁提供侧栏菜单入口，完善侧栏关闭、键盘焦点和弹窗交互，不新增底部导航栏。
- 保持现有颜色、字体、圆角和主题风格，修复窄屏内容溢出及长列表被固定高度截断的问题。

## 使用统计与用户排行

- 使用统计的筛选条件同步作用于顶部整体指标、趋势图、诊断数据和请求明细，刷新时统一更新统计时间范围。
- 管理员请求明细在第一列展示用户信息，成功记录和错误记录均支持；个人使用记录保持当前用户的数据范围。
- 用户排行移入使用趋势卡片，与 Token 用量、请求健康切换展示，表格样式与其他诊断表格保持一致。
- 用户排行默认按总 Token 从高到低排序，表头显示排序方向；后端在截取前 100 位用户之前先按总 Token 排序，避免排行与实际用量不符。

## 订阅额度展示

- 订阅管理、我的订阅和个人资料的分组额度统一使用进度条，清晰展示已用金额、限额及重置时间。
- 没有日限的分组不再展示每日额度行；周额度继续展示，兼容不限额分组。
- 根据使用比例展示正常、临近限额和已达限额状态，重置倒计时自动更新。

## 验证与升级

- 完成手机 390 像素、窄屏 320 像素及桌面 1280 像素的本地浏览器检查，验证菜单导航、筛选联动、排序、全选、详情和弹窗。
- 前端 lint、类型检查、生产构建和 4 项计算测试通过；相关后端观测测试、用户排行回归测试及严格 Clippy 检查通过。
- 不新增数据库迁移，已发布迁移校验通过。
- Docker：`ghcr.io/const-time/codex-proxy-rs:3.8.0`，支持 Linux amd64、arm64；正式发布后同步更新 `latest`。

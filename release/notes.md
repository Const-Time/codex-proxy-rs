# v3.17.1

- 修复部分套餐模型目录刷新失败时，把未获取的目录误判为不支持模型，导致账号被提前过滤并报 no_available_provider 的问题。
- 部分刷新失败时保留同一作用域上次成功获取的模型集合，健康作用域可继续更新；不混用套餐或 API 账号凭据版本的目录，不延长失败目录的缓存时间。成功刷新后仍会移除不再支持的模型。
- 不完整的目录刷新不再被当作 ETag 更新成功，失败自动退避重试；OAuth 未知目录沿用原调度规则，API Key 仍需明确支持证据，分组范围和模型白名单继续生效。
- 请求诊断增加账号预筛选排除原因计数，区分授权范围、模型规则、目录缺失与传输限制，方便定位未发送请求。
- 已通过 OpenAI Provider 全部 815 项集成测试、严格 Clippy、Rust 格式及差异检查。本次无数据库迁移。

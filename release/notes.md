# v3.10.3

## 状态维护页面改版

- 将“State 自动维护”统一改名为“状态维护”，分为运行概览、探测记录和维护配置，复用现有表格、表单、弹窗及分页组件。
- 运行概览按账号分组展示维护项，共享小时预算、预算重置时间放在账号头部；明确展示候选状态、等待原因与诊断，预算耗尽时禁止继续手动排队。
- 维护配置集中管理账号与模型、采集代理和全局策略；保留按账号拉取可用模型并多选添加，高级长度规则折叠展示。
- 账号管理保留指纹和接管开关，将详细维护配置链接到状态维护页面；配置保存保护未提交表单并校验版本，不重置已用小时预算。

## 独立探测记录与指标

- 采集、验证请求改为写入独立探测记录表，不再混入业务请求明细、业务使用统计或用户扣费。
- 支持按账号、精确模型、阶段、处理结果和时间筛选，支持分页、详情及同一轮采集与验证关联查看。
- 展示 HTTP 状态、流完成情况、候选处理结果、耗时、已知 Token、State 字符数、块数、指纹和估算到期时间，不保存 State 原文或凭据。
- 增加探测次数、采集入选率、验证通过率、失败/未入选次数、平均耗时及已知 Token 指标；统计覆盖全部匹配记录，不仅限当前页。
- 区分请求完成、候选入选和验证通过，验证通过不等于候选最终发布；历史未知、进行中和中断未确认记录不伪造结果或 Token。
- 探测记录沿用系统事件保留天数并分批清理。

## 出口 IP 与所属区域

- 展示采集出口和业务出口的 IP、所属区域、检测时间及检测来源，代理测试保留 IPv4/IPv6 结果。
- 复用现有出口检测和自定义 CA 配置，辅助检测在释放账号并发槽之后执行，有界超时及短期缓存，检测失败不影响候选处理。
- 所有 IP 信息明确标注为独立检测快照；轮换/API 代理显示“轮换出口参考”，不将额外检测连接冒充该次上游请求的实际出口。
- 未取得 IP 或区域时显示未确认/未知；概览从近 24 小时最近 100 条探测记录提取出口快照，不补造历史出口。

## 升级须知

- 新增数据库迁移 0024，保持已发布的 0001–0023 迁移不变。首次启动新版本时执行迁移，请提前备份数据库和配置。
- 迁移仅将具有完整系统探测标记的历史记录迁出业务请求表，保留已知事实，不补造历史候选决策或出口信息；业务记录、费用及账本不改写。
- 保留 HTTP/WS 接管、账号开关、指纹收敛、原生续接保护、维护预算、空闲限制及上游限流冷却。
- 不建议新旧版本混跑；回退旧二进制将重新把维护请求写入业务请求表。
- 本次仅发布软件包和镜像，不自动升级或重启线上实例。

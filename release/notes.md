# v3.17.0

- 移植重置卡临期自动使用：在账号的「额度重置」中按账号开启，默认关闭；全局提前时间默认 10 分钟，可设置 1～1440 分钟。
- 支持可选的「剩余周额度上限」，高于上限或无法确认账号周额度时暂不使用。短期、月度和模型专属额度不参与判断。
- 每日错峰发现卡片，临期消费前重新核验；计划和幂等请求持久化，重启、超时及关闭后重新开启均保留未决请求，防止重复消费。
- 明确返回「当前无需重置」时保留卡片并稍后重试；结果未知时沿用原请求 ID。成功后回读官方额度，并保留现有单账号订阅重置联动与账本规则。
- 管理页面复用系统表单组件；保存开关响应失败时重新查询实际状态，避免把已生效的操作显示为未生效。
- 新增 local.settings.v2 设置服务，保留已发布的 v1 字段合同；旧插件更新设置不会覆盖重置卡条件。RPC v7 不变，模型体检插件 v0.11.0 无需重装。
- 新增数据库迁移 0047 保存自动使用设置和到期计划；旧账号默认不启用，不修改已发布迁移。
- 已完成后端工作区回归与 API 整包复测、真实本地 PostgreSQL/Redis 集成测试、严格 Clippy、前端 83 项测试及构建，以及浏览器开关和表单操作验证。

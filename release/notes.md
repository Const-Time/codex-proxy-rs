# v3.11.3

## 入口错误明细修复

- 修复请求在入口被限流拒绝后，错误列表缺少用户、Key、模型等上下文的问题；明确区分用户/Key 的并发限制和请求频率限制。
- 确认未发送的入口拒绝显示“未调用上游”，不再访问不存在的执行诊断；用户仅能查看自己的记录，删除 Key 不丢失已保存的用户归属。
- 从旧错误记录中恢复已有的请求与 Key 关联；没有记录的模型、IP、具体限流类型保持未知。

## 分项计费倍率

- 系统模型定价、批量定价和分组模型倍率均支持“全部费用”，或多选输入、输出、缓存读取、缓存写入。
- 选中费用项应用配置倍率，未选项保持 1 倍；选择全部费用包含非 Token 费用，选择四个 Token 项不改变非 Token 费用。
- 请求费用、分组扣费和额度统计使用同一分项计算规则；倍率按请求冻结，旧配置行为与历史账单保持不变。
- 无可信分项明细的费用保留原额，不猜测拆分；金额展示注明倍率作用范围。

## 升级说明

- 本次仅从 v3.11.2 移植上述修复和分项倍率，不包含开发分支的插件体系与其他执行链路改造。
- 新增数据库迁移 0032、0033，不包含未发布的 0027–0031 插件迁移，已发布迁移字节保持不变。
- 升级前请备份数据库。配置分项规则后，不要直接回退到不支持该规则的旧二进制。
- 发布不会自动升级或重启线上实例。

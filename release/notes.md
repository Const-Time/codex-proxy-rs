# v3.12.3

## 页面响应与资源使用

- 用量汇总、趋势和热点诊断独立更新，较慢或失败的诊断请求不再阻塞其他卡片；错误排查仅在打开对应页签时加载，筛选选项并行获取。
- 移除概览、使用记录及错误记录手动刷新时至少等待 1 秒的限制。概览在后台标签页暂停自动刷新，离开页面或切换趋势时取消失效请求；用户排行筛选增加防抖、取消旧请求并复用当前页面的用户列表。
- 下拉菜单和明细弹层仅在打开时监听全局点击、滚动及窗口变化，减少表格较多时的交互开销。

## 请求记录与功能调整

- 新增独立“速率”列，显示整数 tok/s 和 TTFT；延迟列保留首字与总耗时。缺少首 token 样本时不以首事件时间代替，未记录的数据显示为“—”。
- 插件菜单改用上游同款拼图图标。
- 移除“状态维护”页面及账号“指纹 / Turn-state”入口，停止装配后台主动状态维护任务；历史策略不再自动恢复主动探测。正常请求的会话身份与原生会话续接保留，历史数据不删除。

## 升级与部署

- 修复旧页面在升级后引用已删除脚本时返回首页 HTML 的问题：缺失静态资源返回 404 且不缓存，入口页面重新验证缓存，带版本标识的资源长期缓存。
- 页面模块加载失败时明确提示刷新，避免菜单点击后只有控制台报错。
- 部署文档补充 Nginx/OpenResty JSON 压缩配置。该设置由反向代理管理，升级应用不会自动修改现有站点配置。
- 本地验证通过：前端 69 项、API 474 项、应用组装 43 项和 OpenAI 管理相关 45 项测试，以及前端构建、ESLint、Rust 格式与严格 Clippy 检查。无新增数据库迁移。

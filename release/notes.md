# v4.0.0

## Codex 账号策略

- 账号管理新增「更多操作 → 指纹 / Turn-state」入口，提供独立的「启用指纹收敛」与「接管 turn-state」开关，默认均关闭。
- 指纹收敛在最终账号确定后执行，按账号与客户端隔离 session/thread/turn/window/cache 等已知出站身份，保留 UUIDv7 时间戳和复合窗口序号，对齐请求头与 metadata，不修改用户正文或本地会话亲和。
- 开启指纹收敛后，WebSocket 握手不携带 turn-state，每帧继续使用本轮状态；不会强制 WebSocket 降级为 HTTP。
- 自动接管仅作用于 HTTP 非同轮、非原生续接请求；关闭或没有有效候选时保留原有安全透传逻辑。

## State 自动维护

- 新增管理员维护页面，可配置全局策略、独立探测代理池、精确账号与上游模型，以及暂停、恢复、撤销和刷新操作。
- 支持轮换代理入口或 HTTPS API 提取代理；采集出口与账号业务出口分离，独立探测候选需经过业务出口验证，不重放用户正文。
- 成功完成的非接管 HTTP 请求也可采集实际响应值。候选按账号、精确模型及凭据版本隔离，每项最多保留 3 个。
- 新配置在字符数与块数同时为 0 时使用 292/10 块和 332/12 块两种筛选形态；仍支持显式规则。长度仅是结构观测，不代表模型能力。
- 默认 TTL 为签发时间起 1 小时，重复观测不续期。到期、候选耗尽或返回 312/356 不会因此禁用账号；探测认证失败或限流会暂停维护项，不通过更换出口继续绕过。
- 切换指纹模式或关闭账号接管会撤下该账号候选；旧请求晚到的响应不能重新填回已撤销的候选池。
- 配置与候选使用加密文档保存，配置写入具有版本冲突检测和脱敏审计；页面只显示状态摘要和结构，不回显候选原文或代理密钥。

## 使用统计

- 请求明细继续展示完整值的字符数、截断值与复制按钮，新增「接管」来源标记。
- 详情中分别展示实际发出的状态与实际返回的状态；响应没有返回状态时，使用本次实际出站值并明确标注来源。
- 普通用户的个人使用记录继续隐藏原始 turn-state 及相关内部元数据。

## 升级须知

- 新增 `0022_turn_state_management` 数据库迁移。升级前备份数据库、配置和 `identity_hmac_secret` 文件。
- 所有实例必须保留并使用原有共享身份密钥；丢失或更换密钥会导致旧维护文档无法解密。
- 开关默认关闭。启用接管还需开启全局维护，并配置启用的账号模型维护项和代理池；主动探测会消耗上游额度。
- 开关作用于后续请求，跨实例同步不是瞬时完成；建议没有进行中会话时切换指纹模式。保存通用维护配置会撤下候选并重新验证。
- 执行新增迁移后不要仅回滚应用二进制；如需回退，应恢复升级前数据库备份。
- 本次发布软件包与镜像，不自动更新线上实例，也不会补回历史空白使用记录。

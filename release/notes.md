# v3.11.4

## Fast 档位与计价修复

- 移植上游 `cea4e1d8`：OpenAI Responses 的统计档位与本地费用估算统一使用最终发送给上游的请求档位，覆盖 HTTP 和 WebSocket。
- 出站为 `priority` 时，即使响应回显 `default` 或 `auto`，仍显示 Fast 并按模型登记的 Priority 价格估算；请求档位为 `auto`、未知值或缺少价格时保持费用未知，不猜测价格。
- 请求记录和费用明细分别展示请求档位、上游返回档位与计价档位；原始响应不改写。Fast 标记不保证实际加速，本地估算不代表官方账单。

## 分项倍率结算修复

- 修复请求记录已显示分项倍率、实际额度扣减却仍使用原始金额的问题。结算直接使用执行费用事实，不再依赖可能延迟或丢失的异步请求记录。
- 请求准入时冻结模型倍率与作用项；记录展示和额度账本使用同一份规则，后续修改配置不影响已准入请求。
- 保留重试的逐次费用拆分和幂等结算；Fast 档位选价与系统、分组分项倍率各自应用一次，不重复加价。

## 表格操作按钮布局

- 统一公共表格工具栏，刷新、列设置和其他操作不再分别占行，减少大块空白。
- 覆盖请求记录、错误排查、账号、密钥、代理和订阅等相关页面；窄屏和批量操作自动换行，避免重叠或溢出。

## 升级说明

- 本次基于 v3.11.3，仅发布上述修复，不包含开发分支的插件体系与其他执行链路改造。
- 不新增数据库迁移，不回填历史档位、不重算历史费用或补扣旧账；计价和结算新规则作用于升级后的新请求。
- 升级前请备份数据库；已有分项倍率配置继续保留。
- 发布不会自动升级或重启线上实例。

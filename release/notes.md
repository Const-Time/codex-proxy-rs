# v3.7.2

## 账号额度区间估算

- 账号展开卡片新增“预计总额度”，使用同一额度周期内的区间消费 ÷ 百分比增量计算。例如从 20% 上升到 22%，该区间消费 $10，预计总额度为 $500。
- 加载账号额度时记录上游观测时间与百分比；首次采样只建立起点，累计上升至少 1 个百分点后给出估算，并展示采样消费与百分比增量。接入前已有消费不纳入采样区间。
- 采样状态保存在数据库中，重启后继续使用。重复或过期观测不推进采样；周期变化、百分比回落、计费缺失或无可归属消费时重新采样或显示“待估算”。
- 只对可归属到账号消费的额度窗口估算。结果仅供参考，不改变计费、订阅额度或请求限制；外部使用、模型组合变化、统计留存和上游比例刷新延迟仍可能影响准确性。

## 分组与订阅

- 分组管理新增“用户数”，统计获得该分组授权的未删除用户，包含已禁用用户及默认拥有全部分组权限的管理员，同一用户不因多个密钥重复计数。
- 订阅管理默认按分组名称排序，同组内按邮箱排序，筛选和分页保留此顺序。
- 侧边栏订阅管理图标改为银行卡样式。

## 系统更新与部署排障

- 创建更新锁或写入更新状态失败时，推送具体错误并保留在更新进度中，避免只显示笼统的“服务内部错误”。
- 部署文档补充应用数据、日志目录权限检查和宿主机修复步骤。容器删除了 Linux capabilities，容器内切换 root 并不等于能修改挂载目录属主。
- 本版本不会自动修改服务器目录权限，也不会更改 Redis、PostgreSQL 数据目录的属主。

## 升级与验证

- 新增迁移 0017 保存额度采样状态；已发布迁移 0001–0016 保持原样，升级前备份数据库。
- 管理、API、存储共 628 项测试通过，另有 32 项系统更新测试通过；严格 Clippy、迁移冻结校验、前端 lint、类型检查和生产构建通过。
- 本地浏览器检查账号展开卡片的估算占位和计算依据布局。
- Docker：`ghcr.io/const-time/codex-proxy-rs:3.7.2`，支持 Linux amd64、arm64；正式发布后同步更新 `latest`。

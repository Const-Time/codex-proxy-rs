# v3.5.0

## 新增与调整

- 分组支持指定模型的计费倍率，按“原始模型费用 × 分组模型倍率”计算消费，并用于日/周额度和消费统计。未配置的模型默认 1 倍，历史请求保留当时倍率。
- 管理员创建、编辑用户时可设置最大并发和每分钟请求数（RPM）。同一用户的所有密钥共享限制；普通用户创建、编辑密钥不能自行设置或绕过上限。
- 菜单分为“系统管理”和“我的账户”。系统菜单按概览、用户管理、分组管理、账号管理、使用统计排序，其后保留代理管理、系统设置；个人菜单依次为我的密钥、使用记录、个人资料、主题设置。
- “使用记录”复用完整使用统计页面，提供趋势、筛选、诊断和错误排查，并在后端限定当前用户。管理员的个人页面也只展示本人记录。
- 总 Token 和缓存 Token 合并显示，新增“总消费”卡片，包含已产生费用的失败请求，避免账本和请求费用重复累计。
- 账号管理新增容量列，显示“当前占用 / 总容量”；未单独设置容量时继承运行设置，占用状态不可用时显示“未知”。

## 验证

完成后端全工作区测试、真实 PostgreSQL/Redis 集成测试、Clippy、前端类型检查及生产构建，并通过管理员与普通用户接口和页面验收。回归覆盖跨密钥共享并发/RPM、限流恢复、倍率冻结、结算幂等、额度拦截及个人数据隔离。

## 升级

本版本自动应用 0008、0009 数据库迁移。旧用户共享并发/RPM 默认不限，旧密钥已有限制保留；旧请求和账本按 1 倍保留，修改分组倍率不会重算历史消费。

升级前备份数据库。升级后不能只切回旧镜像，否则旧版本会因缺少迁移而拒绝启动；回退需同时恢复升级前数据库备份。

Docker 镜像：`ghcr.io/const-time/codex-proxy-rs:3.5.0`，提供 Linux amd64、arm64；稳定版标签 `latest` 同步更新。

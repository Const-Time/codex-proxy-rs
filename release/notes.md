# v3.11.1

## 额度费用估算修复

- 少量历史记录缺失费用时，不再阻塞整个周期的费用预测；使用已知费用继续计算，并明确标注「部分估算」。
- 原始费用与倍率后计费分别判断完整性，展示采样区间和当前周期的缺失记录数。
- 修正采样费用展示，区分本周期累计费用与实际采样费用，避免误读预测依据。
- 全部采样费用未知时仍显示待估算；真实零费用保留为零，Token 预测独立计算。
- 不将缺失费用视为零，不使用当前价格重写历史费用，不追扣历史账单。部分估算并非完整费用或未来费用保证。

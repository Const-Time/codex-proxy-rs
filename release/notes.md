# v3.12.5

## 修复插件后台检测能力识别

- 修复宿主 v3.12.4 配合账号模型体检插件 v0.3.0 时，正常管理员页面错误提示“此宿主不支持后台检测 v1”的问题。
- 根据真实调用祖先和根调用图判断后台权限，不再将普通网页自带的 HTTP 上下文误判为嵌套调用。
- 已接受的后台检测不随页面请求结束或关闭而取消；保留原管理员身份，逐次校验本人 Key 的所有权、状态、权限和计费。
- 嵌套 HTTP/模型调用、失效上下文、System 和 AdminApiKey 仍不能创建后台链。失败停止、手动继续，不自动重试结果未知的收费请求。
- 更正插件页面提示，区分随页面取消的直接推理与独立运行的后台检测。

## 升级说明

- 仅升级宿主至 v3.12.5 即可；已有账号模型体检插件 v0.3.0 无需重新安装。
- 本次没有数据库迁移，不清理诊断内容、请求记录或消费账本，也不重算历史费用。
- 回归覆盖真实 HTTP 登录和 SDK 插件进程、页面作用域结束后续调、Key 权限与费用检查、失败停止及停用撤销；使用本地测试服务，未发送真实付费模型请求。

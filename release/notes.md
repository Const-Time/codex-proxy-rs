# v3.10.5

## 用户侧使用记录展示模型路由

- 修复用户侧使用记录接口过滤上游模型字段的问题，请求明细列表与详情现在可查看发送给上游的模型和上游返回模型。
- 沿用现有模型展示样式：原始请求模型显示在首行，发生模型映射或返回模型变化时在下方以箭头展示；模型未变化时不显示额外箭头。
- 保持网关映射与上游返回模型的含义独立，缺失返回模型时不推测或伪造返回值。
- 普通用户及管理员的个人使用记录均适用；上游账号、邮箱、传输诊断和尝试详情等内部字段仍保持隐藏。

## 升级须知

- 相比 v3.10.4 无新增数据库迁移，无需修改配置。
- 历史记录中已保存的模型字段可直接展示，缺失字段不会回填。
- 本次仅发布软件包与镜像，不自动升级或重启线上实例。

## 验证

- 后端 gateway-api 310 项测试、前端 42 项测试通过。
- 新增模型路由展示回归测试，并覆盖个人详情字段可见性与敏感字段隔离。
- 前端 ESLint、类型检查与生产构建通过。

# v3.12.0

## 插件安装与运行

- 管理员可上传可信插件包、配置实例、启停、切换版本、打开管理页面及卸载；实例与私有数据随数据库备份恢复。
- 接入上游固定 SDK 的管理、外部认证、模型目录、路由、调度、重试、中间件、上游适配器、维护、观察和命令行能力。页面推理沿用本人 Key 的原生权限、共享额度、倍率与结算。
- 支持私有状态版本迁移与失败回滚；停用、换版和退出时撤销旧调用，已开始的原生写入按原事务完成收尾。
- 修复插件直接返回合法 JSON 错误时被误判、导致进程失效和连接中断的问题。

## 执行链稳定性

- 请求配置、权限和倍率按准入快照传递；插件子调用仍使用原生路由、费用结算和取消链。
- 长请求的 Key、用户及账号并发租约持续续期，租约丢失会取消执行；已发送或结果不确定的副作用不能被自动重放。
- 普通请求默认不设总执行期限，连接、握手及接收空闲超时仍生效；显式总期限从原请求开始计时。插件页面保留其调用时限。

## 共享额度管理插件

- 发布可独立安装的 `cpr.shared-budget-manager` 0.1.0，提供共享额度查询、分组基础限额修改和指定用户订阅重置。
- 重置草稿、确认和回执可恢复；未知结果重试复用同一幂等编号，避免重复清零。用户、订阅、权限、审计和账本继续由宿主负责。

## 兼容与升级

- 保留 v3.11.4 的 Fast 档位计价、分项倍率结算和表格布局修复。
- 官方 workbench 0.3.1 Linux amd64 原包及使用本地 SDK 重建的包，已验证管理业务、文本 JSON/SSE/WebSocket、Images 上传转换，以及页面图片生成和续聊。模型响应使用受控夹具，不代表所有第三方插件或真实上游服务均已验证。
- 本地共享额度使用显式扩展接口；上游独立 Key 预算和本地不存在的完整设置字段仍明确返回 unsupported，不做隐式替代。完整支持矩阵见 `docs/plugins.md`。
- 升级前备份 PostgreSQL。此次新增插件相关迁移；使用启动迁移补齐旧版迁移集合，已有用户、Key、订阅、倍率和费用历史保持原样。数据库降级须恢复升级前备份，不能仅替换旧二进制。
- 插件以可信本地进程运行，应仅安装可信来源。Linux amd64、Linux arm64、macOS arm64 分别使用匹配平台制品；不提供 Windows 插件制品兼容保证。
- 发布不会自动升级或重启线上实例。

## 发布产物

- Docker：`ghcr.io/const-time/codex-proxy-rs:3.12.0`，Linux amd64/arm64；稳定标签 `latest` 同步更新。
- Linux amd64、Linux arm64、macOS arm64 网关归档内附 `cpr-plugin` CLI；另提供三平台共享额度管理插件包。
- 提供部署模板、校验和与构建证明。

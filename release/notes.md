# v3.5.1

## 修复与调整

- 修复删除全部密钥后，分组仍因历史额度窗口或计费账本而无法删除的问题。删除不再清除或受阻于历史账本；账号本身、历史消费和在途请求结算均保留。仍绑定密钥的分组继续禁止删除。
- 修复部分 SOCKS5 代理在 Codex WebSocket 测试和实际请求中误报认证失败的问题：合并发送握手头和认证方式，兼容将首个 TCP 片段当作完整握手的代理；保持本地/远端 DNS、认证、TLS 和禁止直连回退的行为。
- 账号容量列移至“平台/类型”和“状态”之间。
- 分组模型倍率改为下拉选择，汇总关联账号的全部模型并去重；支持刷新、部分加载失败提示，保留原已配置模型。
- 账号连接测试独立展示实际测试提示词和模型文本响应，继续保留事件轨迹及错误诊断。
- 系统管理菜单中的“使用统计”移至“代理管理”之后。

## 验证

后端全工作区测试、真实 PostgreSQL/Redis 集成测试、Clippy、前端类型检查及生产构建通过。覆盖无密钥分组删除、历史记录保留、在途结算与幂等、SOCKS5 认证/DNS/TLS/无直连回退，并完成页面验收。

真实代理复测确认握手兼容修复后可到达 Codex，未携带账号凭据时返回 HTTP 401；401 代表目标响应，不代表已完成 WebSocket 101 升级或账号模型调用。代理线路本身仍可能出现超时。

## 升级

自动执行新增迁移 0010，仅解除历史账本对分组配置的外键依赖，保留全部历史金额及归属。升级前备份数据库；回退旧镜像需同时恢复升级前数据库备份。

v3.5.0 暂时不能升级时，可参考部署说明中的应急 SQL，仅清理没有密钥、账本、在途请求的零消费空窗口；不要清空消费表。

Docker：`ghcr.io/const-time/codex-proxy-rs:3.5.1`，支持 Linux amd64、arm64，`latest` 同步更新。

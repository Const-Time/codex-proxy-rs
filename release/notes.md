# v3.6.2

## 订阅配额自动重置开关

- 系统设置的运行参数中新增“自动重置订阅分组配额”，默认开启，保存后立即生效。
- 关闭后，账号主动重置及上游周窗口变化不再联动清零关联分组的用户日、周配额。订阅管理中的手动重置，以及订阅自身到期刷新不受影响。
- 重新开启时重建账号窗口基准，不补做关闭期间的重置；关闭期间已处理的账号重置事件在重试时也不会重复清零。
- 旧客户端保存设置时若未传入该字段，会保留当前开关状态。

## 邮箱登录与用户编辑

- 登录账号统一为邮箱，新建和编辑用户均可填写或修改邮箱，前后端校验格式并拒绝重复邮箱。
- 已有邮箱用户名直接沿用，无需重建用户。用户 ID、密码、密钥所有权、授权分组、配额及历史记录保留；修改后使用新邮箱与原密码登录。
- 管理员可修改自身邮箱且保留当前会话。登录须明确填写邮箱，取消省略账号时回退默认管理员的旧行为；旧非邮箱账号需由管理员改为邮箱后登录。

## 账号容量显示

- 容量数字前增加网格图标，使用中显示绿色，零用量使用默认文字色，与分组容量样式保持一致。

## 升级与验证

- 新增迁移 0013 保存开关及重新开启时的观察基准处理，历史迁移保持不变。升级前备份数据库。
- 全量 2,046 项后端测试、严格 Clippy、前端 lint、类型检查和生产构建通过。
- 验证开关持久化、关闭期间不重置、手动重置可用、重新开启不补重置、旧事件去重，以及邮箱登录和改名后的身份与数据保留。
- Docker：`ghcr.io/const-time/codex-proxy-rs:3.6.2`，支持 Linux amd64、arm64，`latest` 同步更新。

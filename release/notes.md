# v3.7.0

## 用户身份与个人账户

- 登录邮箱与可选的自定义用户名分开，新建和编辑用户可分别设置。仍使用邮箱登录，用户名不要求唯一。
- 已有邮箱账号无需重建；保留用户 ID、密码、密钥、授权分组、配额及历史请求，未设置用户名时显示邮箱。
- 订阅管理与用户管理统一搜索、选择框和复选框样式，可搜索邮箱或用户名。
- 左下角显示在线状态和当前登录名，退出按钮与登录名同排；银行卡图标打开“我的订阅”，展示本人的日、周额度和刷新时间。
- 底部工具卡片缩窄、两行对齐、统一背景；侧栏收起后退出按钮位于订阅上方。关于页面作者更新为 Const-Time。

## 密钥与使用统计

- 密钥分组显示颜色和名称，可在列表中直接切换到已授权分组。
- 分组后新增当前并发列，定时刷新有效请求数；移除密钥层面的并发、RPM 展示和编辑，继续由用户级限制统一控制。
- 移除使用统计及个人账户页面的通用搜索框。请求明细支持通过邮箱、用户名和密钥筛选，并保留分组、账号、模型与接入类型筛选。
- 个人使用记录及密钥选项始终限定为当前登录用户。
- 系统使用统计新增用户排行弹窗，沿用当前时间范围与平台筛选，按请求量展示前 100 位用户的请求数、Token 和消费。消费使用请求发生时的计费倍率。

## 操作日志

- 系统管理新增操作日志，记录登录、管理修改、敏感操作及鉴权失败，支持操作者邮箱、路径、IP、方法、认证方式、结果和时间范围筛选。
- 日志详情展示请求 ID、操作者、结果、耗时和关联变更字段；不记录密码、完整密钥、请求正文或敏感请求头。
- 连接 IP 与未经可信代理验证的上报 IP 分别展示。日志按系统审计日志保留天数清理。
- 宽屏下筛选项及查询按钮一行完整展示，窄屏按可用空间换行。

## 升级与验证

- 新增迁移 0014、0015，分别保存可选用户名和操作日志；已发布迁移 0001–0013 保持原样。升级前备份数据库。
- 后端全量测试、新增审计回归测试、严格 Clippy、迁移冻结校验，以及前端 lint、类型检查和生产构建通过。
- 本地页面验证邮箱登录与改名保留数据、个人权限隔离、密钥分组切换、当前并发、排行消费、日志详情及侧栏展开/收起。
- Docker：`ghcr.io/const-time/codex-proxy-rs:3.7.0`，支持 Linux amd64、arm64，正式发布后 `latest` 同步更新。

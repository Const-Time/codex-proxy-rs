# v3.11.2

## Desktop 版本检查修复

- 适配官方安装包新的 CodexCLI.app 目录，从实际 Core 可执行文件读取版本，修复「上游请求身份」的发布检查失败。
- 排除旧路径、CLI 启动脚本和重复 Core 条目，避免错误识别版本。官方 Desktop 26.928.20755 安装包已实测提取 Core 0.159.0。

## 上游修复移植

- 停用 OAuth 账号仍可刷新凭据，刷新不会重新启用账号；额度查询失败保留原有凭据和额度事实，并返回安全错误。
- 模型目录按来源账号、分组和 Key 授权范围过滤；配置保存复用缓存并抢占慢刷新，后台继续对账，减少保存等待。
- 改善 WebSocket 关闭与退出诊断，将 1009 识别为请求过大；符合条件的大请求发送前转 HTTP，无法安全降级的增量续接要求完整历史重放。
- 隔离受管请求头与 parent_response_id，response.interrupt 只控制当前响应的原 WebSocket。
- 移除 Provider 全局熔断，保留连接保护；可靠 NotSent 失败共享重试预算，限制建连资源，入口拒绝保留观测记录。
- Responses 预提交窗口调整为 128 KiB 或 2.5 秒；区分暂时容量不足与无可用账号，固定自更新后的重启路径，恢复默认 HTTP 空闲连接策略。

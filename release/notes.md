# v3.8.7

## 请求详情时间显示

- 成功及失败请求详情的时间明确标注为“请求时间（UTC+8）”，避免误认为已经按代理时区显示。
- “上游请求参数”新增“请求时间（代理时区）”，按所选请求的发生时间及各次尝试保存的时区快照换算，同时标注时区名称和 UTC 偏移。
- “出口检测时间”更名为“上次出口检测时间”，明确区分代理检测与请求发生这两个不同的时刻。
- 查看关联请求时使用该请求自身的时间；缺失请求时间时显示“—”，不使用代理检测时间代替。
- 原始时间线及导出诊断包保持不变，无需重新采集已有完整快照。

## 验证与升级

- 前端 16 项测试、lint、类型检查和生产构建通过，覆盖请求与检测时间区分、各次尝试的时区换算及缺失时间。
- 本次为前端显示修复，无新增数据库迁移。
- Docker：`ghcr.io/const-time/codex-proxy-rs:3.8.7`，支持 Linux amd64、arm64；正式发布后同步更新 `latest`。

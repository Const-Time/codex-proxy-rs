# v3.18.10

- 账号新增每日允许调度时段：默认关闭，支持多时段、跨午夜和时区。范围外不再分配新请求，已开始的请求正常完成；固定账号和诊断探测同样遵守限制。
- 修复 LiteLLM 远程价格同步被扩展字段阻断的问题，保留 SHA-256 校验、人工价格及倍率，并区分下载、格式和摘要校验失败。
- 模型目录按账号持久化并支持启动恢复；普通查询不等待上游刷新，刷新期间保留明确的模型权限排除，统一使用服务端请求画像。
- 移植 WebSocket 背压取消、握手消息上限、NO_MORE_RETRY、无状态码错误分类及不可达代理端点排除等稳定性修复，更新相关网络依赖。
- 插件调度能力升级到 v4，提供候选可用性、会话绑定、角色和过滤委托；新增按窗口分页读取历史额度观测的接口。使用旧版 scheduler 能力的插件需要适配；现有模型体检插件不依赖该能力，已完成兼容性测试，无需重装。
- Linux / Docker 与 macOS 独立打包和发布，避免单个平台阻塞其他平台出包；全部平台完成后再更新完整在线升级索引。

升级会自动应用数据库迁移 0053 和 0054。现有账号默认不启用调度时段限制。
